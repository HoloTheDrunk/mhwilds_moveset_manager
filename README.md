# MHWilds Moveset Manager
Allows the definition of move swaps to change how weapon moves string together (among other things).

# Installation
### .zip archive from NexusMods
Move the `moveset_manager.lua` to the `reframework/autorun/` folder.
Any files with extension .moveswap placed in the `reframework/data/` folder will be automatically loaded on launch or when pressing `Reload` in the mod's UI.
### This repository
Run `compile.lua` and then same as above but with the resulting `output.lua` file (you can rename it of course).
